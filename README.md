# FutCaller — distribution

Installateurs desktop et mises à jour de FutCaller. Le code source est conservé dans un dépôt privé.

Les versions validées sont disponibles dans [Releases](https://github.com/quentinvdlpro/FutCaller-releases/releases). Chaque version contient son changelog, les installateurs, les signatures de mise à jour et les sommes SHA-256.

L’application lit le flux [latest.json](https://github.com/quentinvdlpro/FutCaller-releases/releases/latest/download/latest.json). Une release en brouillon ne déclenche aucune mise à jour.
